# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation in opennbLM a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity, experience, education, socio-economic status, nationality, appearance, race, caste, color, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that helps:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Accepting responsibility for mistakes
- Focusing on what is best for the community

Examples of unacceptable behavior:

- Sexualized language or imagery, and unwelcome sexual attention
- Trolling, insulting comments, and personal or political attacks
- Public or private harassment
- Publishing others’ private information without permission
- Other conduct that would be reasonably considered inappropriate

## Enforcement

Report issues to the maintainers through GitHub (private security contact is in [SECURITY.md](SECURITY.md); conduct issues can use a private maintainers email if published, otherwise open a maintainer-only report).

Maintainers may remove, edit, or reject comments, commits, code, wiki edits, issues, and other contributions that do not match this Code of Conduct.

## Scope

This Code of Conduct applies in project spaces and when a person is representing the project in public.
