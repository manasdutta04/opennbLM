## Agent Continuity Rule

Before modifying the project, always read:
1. .agents/AGENTS.md
2. .agents/progress.md
3. the relevant specialized agent markdowns

After modifying the project:
1. update progress.md
2. update relevant architecture/feature markdowns
3. record new decisions
4. record limitations
5. never claim untested functionality works

The `.agents/` directory is part of the source of truth for the project.

Do not delete or overwrite agent context merely to make it shorter.

If implementation and agent documentation disagree:
- inspect the actual code
- determine the current behavior
- update the documentation
- do not blindly follow stale instructions.
