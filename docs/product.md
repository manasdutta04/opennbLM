# Product

opennbLM is a native desktop, voice-first AI learning companion. The user chooses the brain; Rumik is the voice.

The product is desktop-first and local-first, with persistent local conversations and configurable BYOK providers. It does not require accounts, a remote backend, Docker, or a web SaaS deployment.

OpenMausBot is product interaction inspiration only. Its source, branding, assets, mascot, and implementation are not used.

The current foundation intentionally does not implement chat, learning flows, memory behavior, or voice playback.
