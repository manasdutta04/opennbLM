# Rumik Runtime

Rumik-OSS-1 is opennbLM's defining local voice engine and is modeled as a first-class runtime integration. It is not interchangeable with arbitrary cloud TTS and this project is not a generic TTS marketplace.

The `@opennblm/rumik-runtime` package currently contains only lifecycle and speech contracts. A Python/Rumik sidecar may be used where required. Bundling, licensing, executable discovery, model distribution, and shutdown behavior must be verified before claiming packaged support.
